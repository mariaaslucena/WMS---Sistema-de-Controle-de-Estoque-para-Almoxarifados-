# WMS Sistema de Controle de Estoque-para Almoxarifados
Projeto Integrador desenvolvido para o Centro Universitário Senac (Análise de Soluções Integradas para Organizações)

## Visão Geral do Produto

O **WMS (Warehouse Management System)** é uma plataforma web dinâmica desenvolvida para otimizar a gestão logística e o controle de estoque de um almoxarifado central escolar. O objetivo principal da solução é substituir processos manuais e planilhas estáticas por um sistema automatizado que assegure a integridade dos saldos, a rastreabilidade total das movimentações e a eficiência na distribuição de insumos para as unidades escolares atendidas.

### Diferencial Inovador: Matriz Visual Interativa
Em vez de depender de tabelas puramente textuais, o sistema renderiza graficamente a estrutura real do galpão físico, organizada em **Ruas (de 'A' a 'G')** e **Posições horizontais (de 1 a 40)**. 

Por meio de codificação por cores gerenciada via programação back-end, o operador visualiza em tempo real a situação do almoxarifado
- **Verde:** Posições livres para recebimento e armazenagem de novos materiais.
 - **Vermelho / Azul:** Posições ocupadas, permitindo consulta direta dos itens e registro ágil de saídas.

---

## Principais Funcionalidades (MVP)

- **Controle de Acesso e Autenticação:** Acesso seguro com perfis diferenciados para Operadores e Gestores de Logística.
- **Mapa de Estoque Interativo:** Visualização rápida do status físico do galpão por rua e posição.
- **Registro de Baixas Automatizado:** Interface via janelas modais para confirmação de saídas de materiais vinculadas às escolas de destino.
- **Emissão de Guia de Remessa:** Geração automática de relatórios formais em formato PDF para acompanhar o transporte da carga física
- **Módulo de Auditoria e Relatórios:** Filtros por período, tipo de movimentação e unidade escolar para controle gerencial e prestação de contas.
