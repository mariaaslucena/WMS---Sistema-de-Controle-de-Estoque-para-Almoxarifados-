# WMS Sistema de Controle de Estoque-para Almoxarifados
Projeto Integrador desenvolvido para o Centro Universitário Senac (Análise de Soluções Integradas para Organizações)

## Visão Geral do Produto

O **WMS (Warehouse Management System)** é uma plataforma web dinâmica desenvolvida para otimizar a gestão logística e o controle de estoque de um almoxarifado central escolar[span_1](start_span)[span_1](end_span). O objetivo principal da solução é substituir processos manuais e planilhas estáticas por um sistema automatizado que assegure a integridade dos saldos, a rastreabilidade total das movimentações e a eficiência na distribuição de insumos para as unidades escolares atendidas[span_2](start_span)[span_2](end_span).

### Diferencial Inovador: Matriz Visual Interativa
Em vez de depender de tabelas puramente textuais, o sistema renderiza graficamente a estrutura real do galpão físico, organizada em **Ruas (de 'A' a 'G')** e **Posições horizontais (de 1 a 40)**[span_3](start_span)[span_3](end_span). 

Por meio de codificação por cores gerenciada via programação back-end, o operador visualiza em tempo real a situação do almoxarifado[span_4](start_span)[span_4](end_span):
- **Verde:** Posições livres para recebimento e armazenagem de novos materiais[span_5](start_span)[span_5](end_span).
 - **Vermelho / Azul:** Posições ocupadas, permitindo consulta direta dos itens e registro ágil de saídas[span_6](start_span)[span_6](end_span).

## Principais Funcionalidades (MVP)

- **Controle de Acesso e Autenticação:** Acesso seguro com perfis diferenciados para Operadores e Gestores de Logística[span_7](start_span)[span_7](end_span).
- **Mapa de Estoque Interativo:** Visualização rápida do status físico do galpão por rua e posição[span_8](start_span)[span_8](end_span).
- **Registro de Baixas Automatizado:** Interface via janelas modais para confirmação de saídas de materiais vinculadas às escolas de destino[span_9](start_span)[span_9](end_span).
- **Emissão de Guia de Remessa:** Geração automática de relatórios formais em formato PDF para acompanhar o transporte da carga física[span_10](start_span)[span_10](end_span).
- **Módulo de Auditoria e Relatórios:** Filtros por período, tipo de movimentação e unidade escolar para controle gerencial e prestação de contas[span_11](start_span)[span_11](end_span).
